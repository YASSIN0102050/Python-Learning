1. Variables & Data Types

Think of a variable as a labeled box. You put something inside and give it a name so you can use it later. Python automatically knows the type – you don’t have to tell it! 
name = "Yassin"          # string (text)
age = 16                 # integer (whole number)
height = 1.75            # float (decimal)
is_student = True        # boolean (True/False)

print(name)
print(type(age))         # shows <class 'int'>

2. Numbers & Math Operations

Same symbols you already know: + – * / // % ** 
a = 10
b = 3
print(a + b)   # 13
print(a // b)  # 3   (floor division)
print(a % b)   # 1   (remainder)
print(a ** 2)  # 100 (power)

3. Strings & f-strings

Strings are text. Use f-strings (Python 3.6+) – the easiest way to mix text and variables. 
name = "Yassin"
age = 16
print(f"Hello, my name is {name} and I am {age} years old.")

4. Getting Input from User

name = input("What is your name? ")
age = int(input("How old are you? "))   # convert to number

5. if – elif – else (Decision Making)

age = int(input("Enter your age: "))

if age >= 18:
    print("You can drive and vote!")
elif age >= 13:
    print("You are a teenager!")
else:
    print("You are still a kid 😊")

6. Loops – for & while

# for loop
for i in range(5):          # 0,1,2,3,4
    print("Hello", i)

# while loop
count = 1
while count <= 5:
    print(count)
    count += 1

7. Lists (Your First Data Structure)

A list is like a shopping list – ordered and changeable. 
fruits = ["apple", "banana", "cherry"]
fruits.append("mango")
print(fruits[0])        # apple
print(len(fruits))      # 4
for fruit in fruits:
    print(fruit)

8. Functions – Reusable Code

def greet(name, age=18):
    print(f"Hello {name}! You are {age} years old.")

greet("Yassin", 16)
greet("Sara")   # uses default age

Project 2: Simple Calculator

num1 = float(input("First number: "))
num2 = float(input("Second number: "))
op = input("Operation (+ - * /): ")

if op == "+":
    print(num1 + num2)
elif op == "-":
    print(num1 - num2)
